# Portfolio · Gora Dia Wade

Portfolio personnel de **Gora Dia Wade**, développeur web orienté automatisation et intelligence artificielle, basé à Longueuil (Québec).

Site d'une page, bilingue français / anglais, thème sombre, responsive.

## Stack

- **React 18** (chargé par CDN, sans build)
- **JavaScript (JSX)**, **CSS** (variables, grid, `color-mix`)
- **Claude Design** pour la maquette, **Claude Code** pour l'intégration
- **GitHub** + **Netlify** (déploiement automatique à chaque push)

## Structure

```
.
├── site/
│   ├── index.html        # Point d'entrée
│   ├── data.jsx          # Tous les contenus FR / EN
│   ├── components.jsx    # Composants réutilisables
│   ├── homepage.jsx      # Sections de la page, langue, animations
│   └── assets/           # Styles et photo
├── netlify.toml          # Netlify publie le dossier site/
└── prompt-claude-design.md  # Brief de départ
```

## Lancer en local

Ouvrir `site/` avec l'extension **Live Server** de VS Code (clic droit sur `index.html`, puis **Open with Live Server**).
